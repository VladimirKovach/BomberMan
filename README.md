# Bomberman
Un gioco Bomberman scritto in C++ usando la libreria ncurses.


## Installazione
Installa ncurses:
```bash
sudo apt install libncurses-dev
```


## Compilazione
Compila il programma:
```bash
make
```

Rimuovi l'eseguibile e i file oggetto:
```bash
make clean
```


## Esecuzione
Esegui il programma:
```bash
./bomberman
```


## Comandi

### Gioco
| Tasto | Descrizione |
| :--- | :--- |
| `FRECCE` / `WASD` | muovi giocatore |
| `SPAZIO` | piazza bomba |
| `Q` | termina partita |

### Menu
| Tasto | Descrizione |
| :--- | :--- |
| `↑` `↓` | naviga |
| `INVIO` | seleziona |
| `Q` | esci |
